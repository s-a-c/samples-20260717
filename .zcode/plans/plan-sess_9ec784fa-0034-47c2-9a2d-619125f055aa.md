## Goal

Enable terminal font-size control in ZCode by flipping `terminalInheritSystemProfile` to `true`, so the embedded terminal's font **size** is pulled from your macOS Terminal.app default profile while keeping your custom font **family** (Atkinson Hyperlegible Mono et al.).

## How it works (verified from the app source)

ZCode's `resolveTerminalFontProfile()` resolves the terminal font like this:

- If `terminalFontFamily` is set (yours is) → the **family** is your custom list, AND `fontSize` is taken from the detected system profile **only when `terminalInheritSystemProfile !== false`**.
- Currently `terminalInheritSystemProfile: false`, so you get `fontSize: undefined` (xterm default ≈ 12–14px), with no way to change it.

Flipping it to `true` gives: **your custom family + system-profile font size**. You then control the terminal size by changing the font size in your macOS Terminal default profile.

## The change (single file, two-line edit)

**File:** `~/.zcode/v2/setting.json`

1. Line 11: change `"terminalInheritSystemProfile": false,` → `"terminalInheritSystemProfile": true,`
2. Leave line 12 (`terminalFontFamily`) **unchanged** — keeping your custom family is what makes this a "size only" change rather than also inheriting system colors/behavior via the family path. (Note: `theme` _will_ also be inherited alongside fontSize per the resolver; see caveat below.)

## Pre-flight (read-only, recommended but not required)

- Inspect current macOS Terminal default profile + its font size so you know the starting point: read `~/Library/Preferences/com.apple.Terminal.plist` (`Default Window Settings`), then in Terminal.app → **Settings → Profiles → [that profile] → Font** to see/adjust the size. (These reads were blocked by the sandbox in investigation, so you'll do this step manually.)

## Post-change steps

1. **Quit and relaunch ZCode** — `setting.json` is read at startup; the terminal resolver won't pick up the change in a running session.
2. Open the integrated terminal and confirm the size matches your Terminal.app profile.
3. To change terminal size from now on: adjust the font size in **Terminal.app → Settings → Profiles → (default profile) → Font**, then relaunch ZCode.

## Caveats / things to know

- **Theme is also inherited.** Per the resolver, enabling inherit mode pulls `fontSize` _and_ `theme` from the system profile (your custom family still wins for the font itself). If you don't want your terminal colors to change to the macOS Terminal profile's colors, this trade-off comes along with the size inheritance. If that's unacceptable, the only alternative is `desktopZoomLevel` (whole-app zoom) instead.
- **Sandbox note:** the sandbox blocked `plutil`/`defaults` reads of `com.apple.Terminal.plist` during investigation. Editing `~/.zcode/v2/setting.json` itself is not expected to be blocked (it's a regular JSON file under your home dir), but if it is, I'll ask you to either approve the edit or make the one-line change by hand.

## Out of scope

- No changes to the ZCode app bundle or to `~/.zcode/cli/config.json` (that file holds MCP/plugins, not terminal UI).
- No filing of an upstream feature request for a native `terminalFontSize` setting (can do separately if you want).

## Validation

- After relaunch: integrated terminal renders at your macOS Terminal profile's font size.
- Confirm family unchanged (still Atkinson Hyperlegible Mono) by eye.
