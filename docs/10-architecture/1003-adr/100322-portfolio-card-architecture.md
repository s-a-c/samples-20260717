# 0011 - Portfolio Card Architecture

## Status: Proposed

## Context

Portfolio cards represent sample product records across domains.

## Decision

Define a unified schema for portfolio cards supporting Chinook, Northwind, and Pagila.

## Consequences

- Ensures consistent presentation across products
- Facilitates cross-product search
- Requires domain-specific adaptations
